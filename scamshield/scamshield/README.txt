SETUP (2 minutes)
1. Get a free Gemini API key: aistudio.google.com/apikey
2. Open chrome://extensions, turn on Developer mode (top right).
3. Click "Load unpacked" and select this scamshield folder.
4. Click the ScamShield icon, paste the API key, choose a language, click Save settings.
5. On any web page: select text, right-click, "Check with ScamShield". Or paste text in the popup.

After editing any file, click the reload icon on the extension card in chrome://extensions.
If you see a 404 / model error, change MODEL at the top of background.js.
The card does not show on chrome:// pages or the Web Store; use the popup there.
